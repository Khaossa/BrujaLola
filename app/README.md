# App Module

This directory contains the main application module for the DivinationApp project.

It includes:
- Kotlin source code under `src/main/java`
- AndroidManifest.xml under `src/main`
- Resources (layouts, strings, colors, themes) under `src/main/res`
- Unit tests under `src/test/java`
- Instrumented tests under `src/androidTest/java`
- Module-level build configuration in `build.gradle`
